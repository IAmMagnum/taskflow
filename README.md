# TaskFlow - Kanban Board Application

A full-stack Kanban task management application built with React, Vite, Express, and SQLite.

## 🚀 Features
- Create, update, filter, and delete tasks across custom columns.
- Filter tasks by priority (Low, Medium, High).
- RESTful API backend integrated with SQLite database.

## 🛠️ Tech Stack
- **Frontend:** React, Vite, Tailwind CSS, Lucide Icons
- **Backend:** Node.js, Express, SQLite

## 📦 How to Run Locally

### 1. Backend Setup
```bash
cd backend
npm install
node seed.js
node server.js

### 1. Frontend Setup
cd frontend
